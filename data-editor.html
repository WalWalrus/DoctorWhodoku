Bulk import game data

Merge existing game-format JSON files or a bundle with characters, episodes, appearances and categories arrays. Existing values and evidence are kept; conflicts are listed for review. TVmaze episode and cast JSON exports are recognised and converted automatically, with any filename. Embedded TVmaze guest casts create Unreviewed episode links. All supplied series are imported; ambiguous identities are skipped and listed for review.
